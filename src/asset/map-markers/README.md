# 地図カテゴリマーカー

料理イラストは画像生成で作成したオリジナル素材。
`source/generated-*.png` に透過256px版を保持する。

- 全21カテゴリを20種類の料理イラストで表示。焼肉とステーキ/ハンバーグは共用。
- 対応表は `src/lib/map-markers.ts`。
- 配信用PNGは68×68。通常表示はズーム10以下で0.22倍、12で0.3倍、14で0.42倍、15以上で0.5倍へ補間。選択時は0.6倍を維持。
- 元絵を46pxに縮小し、白い丸の中心へ合成。
- 通常: 外周 `#24354b`、内側白。選択: 外周 `#2464ff`、内側白。選択時も料理の色を維持。
- 丸枠はMaterial Design Icons 7.4.47の`circle`由来。`source/circle.svg`と`LICENSE`を参照。
- 合成はSharpを使用。アプリ実行時の追加ライブラリや外部アイコン配信への通信は不要。
- 以前のライブラリ由来アイコンは互換用に保持するが、地図は`generated-*.png`のみ読み込む。

縮小時も店舗の存在が分かるよう、アイコンの重なりによる間引きは行わない。
店名は衝突回避を維持し、空いている場所にだけ表示する。
